# مدرسة صلاح الدين للقرآن الكريم — الحفل السنوي لتكريم الدارسين 2025–2026

تطبيق ويب رسمي مخصص للحفل السنوي لتكريم المتفوقين بمدرسة صلاح الدين للقرآن الكريم، مصمم خصيصاً للهواتف الذكية باللغة العربية (RTL) بهوية بصرية إسلامية راقية باللون الأخضر الملكي والذهبي والعاجي.

---

## 🌟 مميزات التطبيق

1. **بحث فوري وذكي في الأسماء وأرقام المقاعد**:
   - تطبيع تلقائي للهمزات (`أ`, `إ`, `آ`, `ٱ` إلى `ا`).
   - إزالة التشكيل (الحركات والتنوين) وعلامات الضبط القرآني والتطويل (`ـ`).
   - دعم الأرقام العربية المشرقية (`١`, `٢`, `٣`...) وتحويلها لأرقام المقاعد بدقة.
   - بحث ضبابي (Fuzzy Search) عبر `Fuse.js` لاكتشاف الأسماء عند وجود أخطاء إملائية طفيفة.
   - دعم الأسماء الجزئية والمركبة.
2. **فصل الغموض وتفادي الالتباس**:
   - عند وجود أكثر من طالب بنفس الاسم، يتم عرض رقم المقعد والمركز والنوع لتمكين الطالب من اختيار سجله بدقة.
3. **كارت تكريم مخصص وفاخر (Award Card)**:
   - نسبة أبعاد عمودية متناسقة تناسب شاشات الهواتف والمشاركة.
   - خطوط عربية واضحة (`Cairo` و `Tajawal`).
   - يحتوي حصراً على البيانات المعتمدة: اسم الطالب، رقم المقعد، المركز المستحق، موعد الحفل، التنبيهات الرسمية، وتوقيع إدارة المدرسة.
   - لا يتم إظهار الحقول الداخلية مثل المجموعة (`مج`) أو الفرقة أو المستوى على الكارت نهائياً.
4. **تحميل فوري بدقة عالية كصورة PNG**:
   - تصدير كامل للكارت بنقاء 2.5x عالي الدقة دون قص.
   - تسمية ديناميكية للملف تلقائياً: `كارت-التكريم-رقم-[رقم المقعد].png`.
   - آلية احتياطية للأجهزة التي تمنع التحميل التلقائي عبر الضغط المطول لحفظ الصورة.
5. **جدول مواعيد الحفل المعتمد**:
   - **المركز الأول / الأولى**: الخميس، 29 أكتوبر 2026.
   - **المركز الثاني / الثانية**: الجمعة، 30 أكتوبر 2026.
   - آخر موعد للحضور 2:00 ظهرًا (يُغلق الباب بعدها).
   - شرط القيد بالمدرسة وسداد الاشتراكات لاستلام الجائزة.

## 🚀 التشغيل المحلي والتطوير

### 1. المتطلبات
- Node.js (الإصدار 18 فما فوق).

### 2. تثبيت الحزم (إن لم تكن مثبتة)
```bash
npm install
```

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح الرابط في المتصفح (عادة `http://localhost:5173/`).

### 4. تشغيل الاختبارات الآلية
```bash
npm test
```
تشمل 17 اختباراً آلياً تغطي:
- تطبيع الهمزات والتنوين والتطويل والمسافات.
- البحث بالاسم الجزئي ورقم المقعد والأرقام العربية.
- تصنيف المراكز وتاريخ حفل المركز الأول (29 أكتوبر 2026) والمركز الثاني (30 أكتوبر 2026).
- التأكد من عدم تخمين تواريخ لمراكز غير معروفة.
- فحص هيكل البيانات وعدم تسريب حقول المجموعة أو الفرقة أو المستوى على الكارت.

### 5. بناء النسخة الإنتاجية
```bash
npm run build
```

## 🖼️ كيفية تحديث أو تغيير الشعار لاحقاً

تم استخدام الشعار الفعلي من ملف `شعار المدرسة2.jpg`.
لتحديث الشعار في أي وقت:
1. استبدل الملف الموجود في المسار:
   - `src/assets/logo.jpg`
   - `public/logo.jpg`
2. أعد بناء المشروع بأمر `npm run build` وسيتم تطبيق الشعار الجديد فوراً في كافة صفحات وتصاميم الموقع وكارت التكريم.

التطبيق جاهز بنسبة 100% للنشر كثابت (Static Site) على منصات مثل:
- **Cloudflare Pages**: مجرد تحديد Build command: `npm run build` ومجلد الإخراج `dist`.
- **Vercel**: يتم التعرف على مشروع Vite تلقائياً وبناؤه بضغطة زر.
- لا يتطلب التطبيق أي خوادم خلفية أو متغيرات بيئة سرية.
